# Pin every plugin EXACTLY and resolve them together in one `uv pip install`.
# Do not install these one-by-one or in separate RUN layers — that lets pip/uv
# resolve each plugin's dependencies in isolation, which is what silently
# breaks NetBox when a second or third plugin is added.
#
# Re-run `docker compose build --no-cache` after every change to this file.

# Pinned to NetBox 4.7.x. Most plugins declare an exact min/max NetBox version
# per release (netbox-bgp 0.20.x, netbox-inventory 2.7.x and
# netbox-floorplan-plugin 0.10.x are 4.7 only), and NetBox silently skips a
# plugin whose range does not match. After any bump, build the image and look
# for NetBox's "Unable to load plugin" warnings in the `docker compose build`
# output.
#
# netbox-secrets is NOT installed: its released 3.1.1 is capped at NetBox
# 4.6.99 and no 4.7-compatible release exists yet (the work is in an unmerged
# pull request). Add it back here, to configuration/plugins.py and to
# extensions/postgis-pathways/configuration/plugins.py once a release
# supports 4.7. Existing secrets stay in the database untouched; see
# docs/OPERATIONS.md.
netbox-bgp==0.20.2

# Alpha-quality (pre-1.0). Pin exact versions, read the changelog before any
# bump, and back up the DB before running migrations after an upgrade.
# 0.6.0 derives fiber paths by analysis (FiberStrandPath) instead of storing
# traced paths, and its migration 0039 deletes all circuit path assignments;
# assign them again with POST /api/plugins/fms/fiber-circuits/<id>/assign/.
# Requires NetBox 4.5+.
netbox-fms==0.6.0

# Hardware inventory tracking. 2.7.x is NetBox 4.7 only; it migrates the
# asset contact field to contact assignments.
netbox-inventory==2.7.1

# TOTP two-factor login. Supports NetBox 4.0-4.99.
# IMPORTANT: otp_required defaults to True upstream, which locks every user
# out at next login until they register a device via `manage.py addtotp`.
# We override it to False below until you're ready to enforce it.
netbox-otp-plugin==1.3.6

# 0.10.x is NetBox 4.7 only (0.9.2 is the last release for 4.6).
netbox-floorplan-plugin==0.10.0

# Alpha software (data model/API may still change). min_version 4.5, no max.
# Optionally integrates with netbox-pathways (soft import, not required).
netbox-wdm==0.2.2
